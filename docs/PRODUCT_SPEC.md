# Clipbox — Product Spec

> Всё важное — под рукой. Всё личное — остаётся личным.

## 1. Позиционирование

Clipbox — персональный local-first Knowledge Hub для Android. Это не «ещё одни заметки», а три
уровня доверия в одном приложении:

| Уровень | Модули | Защита |
|---|---|---|
| **Standard** | Notes, Clips, Reminders, Collections, Tags | Шифрование устройства Android (FBE) + песочница приложения |
| **Private Media** | Изображения, GIF, видео, файлы, приватные коллекции | Собственный ключ, AES-256-GCM (streaming), биометрия/PIN |
| **Vault** | Пароли, логины, ключи, токены, карты, секретные заметки | Собственный ключ, AES-256-GCM, биометрия/мастер-пароль |

Принципы: offline-first, без аккаунта, без сервера, без рекламы и подписок, открытые форматы
(Markdown, JSON), экспорт всего в любой момент.

## 2. Целевой пользователь и ключевые сценарии

Один человек, один (основной) телефон на Android 10+ (minSdk 29, обоснование — ARCHITECTURE §9).

| # | Сценарий | Целевое число действий |
|---|---|---|
| S1 | Увидел ссылку в YouTube/браузере → Share → Clipbox → «Сохранить» | 2 тапа после Share sheet |
| S2 | Быстрая мысль: Add → Note → печать → назад (автосохранение) | 2 тапа |
| S3 | Длинный Markdown-документ с таблицей и кодом, переключение Source ⇄ Preview | 1 тап на переключение |
| S4 | Напомнить про сохранённую статью в субботу 10:00 | из карточки клипа: 3 тапа |
| S5 | Картинка в Telegram → Share → Clipbox → Private Media → коллекция | 3 тапа, файл сразу шифруется |
| S6 | Отправить приватный GIF обратно в Discord | открыть Private → выбрать → Share → приложение |
| S7 | Скопировать пароль из Vault | открыть Vault (биометрия) → поиск → «копировать» (буфер очистится через 30 с) |
| S8 | Перенос на новый телефон | Settings → Backup → обычный ZIP + зашифрованный `.cbvault` |

## 3. Навигация

Нижняя панель (5 позиций):

```
[ Home ]  [ Library ]  ( + )  [ Reminders ]  [ Settings ]
```

- **Home** — блоки: Inbox (неразобранные), Предстоящие напоминания, Недавние, Избранное,
  карточка-вход «Private space». Блоки хранятся как список `{id, visible, order}` в настройках →
  перестановка в будущем без миграций.
- **Library** — сегментный переключатель `All · Notes · Clips` + чипы фильтров (тип, тег,
  коллекция, избранное, архив), сортировка, вид список/сетка. Сверху — глобальный поиск.
- **(+) Quick Capture** — bottom sheet: Note, Markdown, Clip (URL из буфера предзаполняется,
  если там ссылка — только после явного тапа, без фонового чтения буфера), Reminder,
  Private Media, Vault Entry.
- **Reminders** — Сегодня / Предстоящие / Выполненные.
- **Settings** — Тема, Private space (настройки блокировки), Backup & Import, О приложении.

**Private space** — отдельный стек экранов (`/private/...`) с входом через Home-карточку и
Settings. Внутри две вкладки: **Vault** и **Media**. У каждой — свой замок и своя политика
автоблокировки. Защищённые экраны: FLAG_SECURE, скрытие в Recents, блокировка при уходе в фон.

## 4. Функциональные требования MVP

### 4.1 Notes
- Типы: `text` (простой текст, всё равно хранится как Markdown), `markdown`, `checklist`
  (Markdown task list с отдельным UI). «Структурированные записи», таблицы, код, изображения —
  это возможности Markdown, а не отдельные типы.
- Редактор: Source (TextInput моноширинный + панель форматирования: H, B, I, S, цитата,
  список, чек-лист, таблица-шаблон, ссылка, код, разделитель, вложение-картинка) и Preview
  (GFM: таблицы, task lists, strikethrough, вложенные списки, подсветка синтаксиса).
  Галочки в Preview кликабельны и меняют исходник.
- Автосохранение: debounce 800 мс + при уходе в фон; черновики переживают убийство процесса
  (см. ARCHITECTURE §6.2).
- Импорт `.md`, `.zip`, папки Obsidian Vault (через SAF); экспорт `.md`, ZIP со структурой папок
  и вложениями. Frontmatter YAML сохраняется как есть.
- Вне MVP (архитектурно предусмотрено): `[[wikilinks]]`, `![[embeds]]`, callouts, KaTeX, Mermaid —
  Preview рендерится через markdown-it, поэтому это плагины, а не переписывание.

### 4.2 Clips
- Источники: Share Intent (text/URL, image/*, video/*, application/pdf, */*), ручной ввод URL.
- Определение типа по URL-паттернам: youtube, tiktok, reddit, music (spotify/apple/yandex/soundcloud),
  game (steam/itch/epic), ai_tool (настраиваемый список доменов), article, image, pdf, file, link.
- Метаданные: Open Graph → Twitter Card → `<title>`/`<meta description>` → oEmbed (YouTube, TikTok,
  Reddit). Загружаем максимум 512 KB HTML, таймаут 8 с. Превью-картинка скачивается в локальный
  кэш (≤ 1 MB, сжатие до 640px). Ошибка сети ≠ ошибка сохранения: клип создаётся сразу, метаданные
  догружаются фоном со статусом `pending → ok | failed` и кнопкой «повторить».
- Организация: Inbox (`inbox=1` у новых из Share), коллекции, теги, избранное, архив, поиск, сортировка.
- Файлы из Share (PDF и пр.) копируются во внутреннее хранилище `files/attachments/`.

### 4.3 Reminders
- Поля: title, notes, due (локальное время + IANA-зона), repeat rule, ссылка на элемент (опц.),
  статус (active/done/snoozed).
- Повторения: daily / weekly (дни недели) / monthly (число; «31» → последний день) / yearly /
  каждые N минут·часов·дней·недель.
- Действия в уведомлении: «Готово», «Отложить 1 ч». Тело уведомления — только title, без содержимого
  заметки; для элементов Private space напоминания запрещены (не утекает даже заголовок).

### 4.4 Vault
- Типы: login/password, secure note, payment card, Wi-Fi, API key/token, identity document, other.
- Каждая запись: title, тип, поля (типизированные + произвольные, каждое помечено `secret: bool`),
  url, notes, created/updated.
- Генератор: длина 8–128 (по умолчанию 20), классы символов, исключение похожих символов,
  passphrase-режим (EFF wordlist). Источник случайности — `SecureRandom` в native.
- Копирование: буфер помечается `EXTRA_IS_SENSITIVE`, автоочистка через 30 с (настраивается).
- Поиск — только после разблокировки, в памяти, по расшифрованным title/username/url.

### 4.5 Private Media
- Форматы MVP: JPG, PNG, WebP, GIF, HEIC (просмотр если декодер есть), MP4, WebM, MOV (H.264/H.265);
  прочие файлы — хранение и отправка без просмотра.
- Галерея: сетка, полноэкранный просмотр, свайп, pinch-zoom, видео с перемоткой, GIF-анимация,
  сортировка, поиск по имени/заметке, избранное, коллекции, мультивыбор, удаление, перемещение,
  инфо о файле.
- Отправка в другие приложения через `content://` с временным read-грантом (см. SECURITY §7).

### 4.6 Поиск
- Глобальный: Notes, Clips, Collections, Tags, Reminders — SQLite FTS5, префиксный поиск, подсветка.
- Vault и Media — отдельный поиск внутри разблокированного модуля, никогда не в FTS.

### 4.7 Backup & Import
- `clipbox-backup-<date>.zip`: `manifest.json` (версия схемы, sha256 каждого файла), `data.json`,
  `notes/**/*.md`, `attachments/**`.
- `clipbox-private-<date>.cbvault`: отдельный зашифрованный контейнер Vault + Media с отдельным
  паролем бэкапа (Argon2id). Никогда не экспортируется в открытом виде.
- Перед восстановлением — проверка manifest и хэшей; восстановление в транзакции, режимы
  «объединить» / «заменить».

## 5. Нефункциональные требования
- Холодный старт до интерактивного Home ≤ 1.5 с на mid-range (Pixel 6a класс).
- Список 10 000 элементов скроллится 60 fps (FlashList).
- Видео 2 ГБ шифруется/воспроизводится потоково, пиковая RAM < 64 MB на операцию.
- Ни одного сетевого запроса, кроме: метаданные клипа, превью клипа, открытие ссылки пользователем.
- Нет аналитики, нет crash-SDK в MVP (решение: см. ARCHITECTURE §10).
- Accessibility: TalkBack-метки, минимальная цель 48dp, масштабирование шрифта до 200%.

## 6. Вне MVP (явно)
Регистрация, синхронизация, сервер, соц. функции, AI, подписки, встроенный браузер, веб-архив,
совместная работа, iOS, синхронизация с Obsidian, Autofill, плагины Markdown.

## 7. Принятые продуктовые решения по спорным местам промпта

| Тема | Решение | Почему |
|---|---|---|
| «Структурированные записи» как тип заметки | Нет отдельного типа; Markdown + frontmatter | Не плодим закрытый формат |
| Напоминания на элементы Private space | Запрещены в MVP | Иначе title уходит в системные уведомления и SQLite без шифрования |
| Clips «изображения/PDF» из Share | Хранятся как обычные вложения Standard-уровня | Пользователь сам выбирает Private Media, если нужно приватно |
| Лицо как биометрия | Только если устройство даёт Class 3 (Strong) | Class 2 face unlock не может авторизовать Keystore-ключ |
| Восстановление при потере мастер-пароля | Только через Recovery Key (опционально, предлагается при настройке) | Иначе криптографически невозможно — и мы так и пишем в UI |
